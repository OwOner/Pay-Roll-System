# Global Data Safety Rule

**Never delete, truncate, reset, recreate, overwrite, or bulk-modify existing employee, compensation, attendance, timesheet, payroll, cash advance, or historical data unless explicitly approved by the user.**

**Never fabricate attendance records or hours.** Historical attendance must not be silently "fixed" by changing database records. Always preserve the original state of the database and apply changes additively/non-destructively.
